# 宋知意合成角色数据集

## 角色

宋知意，20 岁女性，是用户同校低一年级的学妹，视觉传达设计专业，家在泉州，
目前在厦门读大学。她表面活泼、嘴快、有鬼点子，实际温柔、体贴、敏感。
她对用户暗恋已久但尚未表白，处在暧昧边缘。

完整设定见 [`character_card.md`](character_card.md)。

## 数据来源

宋知意是本项目原创虚构角色。数据由教师模型按角色卡、80 个校园场景和输出 schema 生成。
生成后经过自动格式审查、角色质量审查和跨 split 泄漏检查，没有使用真实用户聊天记录。

## 原始数据

| 文件 | 内容 |
|---|---|
| `source/scenarios.json` | 80 个校园场景 |
| `source/dialogues.json` | 80 段完整多轮对话 |

数据共包含 346 条唯一 assistant 回复：

- 中位长度约 42 个汉字；
- 约 11.85% 的回复含自然问句；
- 约 11.27% 的回复含动作或神态；
- 自动检查未发现重复 assistant 回复或跨 split 重复用户句。

## SFT 数据

| 文件 | 对话数 | assistant 目标数 |
|---|---:|---:|
| `sft/train.jsonl` | 64 | 276 |
| `sft/validation.jsonl` | 8 | 35 |
| `sft/test.jsonl` | 8 | 35 |

`sft/system_prompt.txt` 是训练和推理应优先使用的精简提示。

## 训练与选择

训练配置：

- Qwen3-1.7B；
- LoRA rank 8、alpha 16、dropout 0.05；
- 七个注意力和 MLP 投影层；
- 2 epoch，35 个优化步/轮，共 70 步；
- 学习率 `2e-5`；
- BF16，最大长度 1024。

保存了：

- `epoch-1-half`
- `epoch-1`
- `epoch-2-half`
- `epoch-2`
- 最终 Adapter

自动验证 loss 从 `6.3685` 降至 `3.6651`。但作者实际对比后最偏好
**第 1.5 轮 + 训练同款精简提示**，因为它比完整提示回答更自然、内容更充分。

## 已知限制

- 只有 276 个训练 assistant 目标，分布仍然很小；
- 教师模型审查不能替代多人人工盲评；
- 封存测试仍出现一个“撤回消息”上下文误解；
- 更晚轮数可能因数据量小而过拟合常见表达，loss 下降不等于角色效果持续提升。
